#  AI Job Dashboard Project
Developed by: Disham Lamjana (PSU AI Engineering)

##  Installation
1. สร้าง Virtual Environment: `python -m venv .venv`
2. ติดตั้ง Library ที่จำเป็น: `pip install -r requirements.txt`

##  How to Run
รันคำสั่งหลักเพื่อเปิด Dashboard:
`streamlit run app.py`

##  Features
Dashboard นี้ถูกสร้างขึ้นเพื่อวิเคราะห์ข้อมูลความนิยมของภาษาโปรแกรม โดยมีฟีเจอร์ดังนี้:
* **3 Interactive Charts**: แสดงข้อมูลผ่าน Bar Chart, Pie Chart และ Scatter Plot
* **Sidebar Control**: สามารถเลือกกรองภาษาและช่วงคะแนนความนิยมได้แบบ Real-time
* **Interactive Effects**: มีเอฟเฟกต์ Balloons และ Snow สำหรับตอบโต้กับผู้ใช้งาน

## ### Tools & Libraries
* **Python**: ภาษาหลักในการพัฒนา
* **Streamlit**: Framework สำหรับสร้าง Web Dashboard
* **Plotly Express**: ใช้ในการสร้างกราฟที่สวยงามและโต้ตอบได้
* **Pandas**: จัดการข้อมูล (Data Manipulation)
